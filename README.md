# AHED | عَهْد

مشروع مستقل لتطبيق **عَهْد** للزواج الإسلامي الجاد، يعمل كتطبيق ويب متجاوب على الهاتف والتابلت والكمبيوتر.

## المرحلة الحالية

- تسجيل النساء متاح بسعر 50 درهماً لمرة واحدة بعد قبول وتوثيق الملف.
- تسجيل الرجال موضوع على قائمة انتظار، ثم يفتح بسعر 150 درهماً لمرة واحدة.
- عَهْد Pro للنساء 250 درهماً وللرجال 350 درهماً.
- الموفّق الشخصي للنساء 850 درهماً وللرجال 950 درهماً.
- لا يوجد اشتراك دوري أو تجديد تلقائي.

## ما يعمل في هذا الهيكل

- اختيار نوع الحساب.
- رحلة إنشاء حساب النساء.
- تجهيز الملف ومعايير العمر.
- عرض مراحل التوثيق والخصوصية.
- اختيار الباقة وعرض السعر النهائي.
- قائمة انتظار الرجال دون تحصيل مسبق.
- تصميم متجاوب مع الهاتف والتابلت والكمبيوتر.
- ملفات حقيقية فقط، مع قبول متبادل قبل فتح المحادثة.

## غير مربوط بعد

- قاعدة البيانات وتخزين الحسابات.
- إرسال رمز الهاتف.
- رفع الهوية ومطابقة الوجه.
- الدفع الحقيقي.
- المحادثات والترشيحات.

## التشغيل محلياً

```bash
npm install
npm run dev
```

## النشر على Cloudflare Pages

```bash
npm run build
```

- Build command: `npm run build`
- Output directory: `out`
- Node.js: 20 أو أحدث

المشروع يستخدم هوية AHED وألوان الخمري والشامبانيا والعاجي، ولا يعتمد على أي مشروع آخر.
