# AHED | عَهْد

مشروع مستقل لمنصة **عَهْد** للزواج الجاد، يعمل كتطبيق ويب متجاوب على الهاتف والتابلت والكمبيوتر.

## العناوين الرسمية

- الموقع: `https://ahedmarriage.com`
- البريد: `info@ahedmarriage.com`
- التطبيق بعد ربط النطاق الفرعي: `https://app.ahedmarriage.com`

## المرحلة الحالية

- الموقع التعريفي الرسمي جاهز للمعاينة والربط بالدومين.
- تسجيل النساء مفتوح، والدفع يكون بعد قبول ومراجعة الملف.
- تسجيل الرجال على قائمة انتظار، ويفتح بعد توفر عدد مناسب من الملفات النسائية الحقيقية.
- جميع الأسعار دفعة واحدة، من دون اشتراك دوري أو تجديد تلقائي.
- قاعدة بيانات AHED مستقلة ومتصلة بالتطبيق عبر Supabase.

## الأسعار المعتمدة

| الباقة | النساء | الرجال |
| --- | ---: | ---: |
| عَهْد الأساسي | 50 درهماً | 150 درهماً |
| عَهْد Pro | 250 درهماً | 350 درهماً |
| الموفّق الشخصي | 850 درهماً | 950 درهماً |

تتكوّن الأسعار من رسم الدخول، ثم إضافة 200 درهم لـPro أو 800 درهم للموفّق الشخصي.

## ما يعمل الآن

- موقع رسمي يشرح فكرة عَهْد بوضوح كمنصة زواج لا تطبيق تعارف.
- صفحة رئيسية متجاوبة تشمل المزايا، خطوات الاستخدام، الأمان، الباقات، والأسئلة الشائعة.
- اختيار نوع الحساب.
- رحلة إنشاء حساب النساء.
- حفظ الحساب الحقيقي في Supabase Auth.
- إنشاء ملف خاص تلقائياً بعد التسجيل.
- تأكيد البريد ونقل الملف إلى المراجعة.
- قائمة انتظار الرجال مع سياسات وصول مقيدة.
- قيود العمر والبيانات الأساسية.
- سياسات RLS: كل مستخدم يقرأ ويعدّل ملفه فقط.
- اختيار الباقة وحفظ الباقة المطلوبة.
- تسجيل الدخول ومعاينة الواجهة الداخلية.
- البحث المتقدم، مواصفات الشريك، الحضور، والمنشورات ضمن بنية التطبيق.

## ما يحتاج ربطاً قبل الإطلاق الكامل

- إرسال البريد باسم `no-reply@ahedmarriage.com` وربطه بـResend.
- استكمال تدفق استعادة كلمة المرور وOTP.
- رفع الهوية ومطابقة الوجه.
- الدفع الحقيقي وتفعيل الباقة تلقائياً.
- تشغيل نظام القبول المتبادل والمحادثات على بيانات الإنتاج.
- لوحة الإدارة والموفّق الشخصي.
- ربط `ahedmarriage.com` و`www` و`app` بالاستضافة.
